Name tags

Eight tags, two of each friend. Free to print at home, from the animated series Lumi and the Magical World.

How to use

  1. Print on sticker paper, or plain paper plus tape.
  2. Cut along the dashed lines, eight tags per page.
  3. Write each guest's name on the line.
